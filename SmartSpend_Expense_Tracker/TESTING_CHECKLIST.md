# SmartSpend Manual Testing Checklist

Run these tests in your browser and tick them only after you have verified them.

- [ ] Website opens without a blank page or visible console errors.
- [ ] Navigation links move to the correct sections.
- [ ] Add expense opens the dialog.
- [ ] Submitting with an empty name is blocked by browser validation.
- [ ] Zero or negative amount is rejected.
- [ ] A valid expense appears in the transaction list.
- [ ] Monthly total and remaining budget update.
- [ ] Category breakdown updates after adding an expense.
- [ ] Search matches an expense name or category.
- [ ] Category filter limits the visible transactions.
- [ ] Remove asks for confirmation and then removes the item.
- [ ] Updating the budget changes the progress indicator.
- [ ] Refreshing the page keeps expenses and budget in the same browser.
- [ ] Test layout at a narrow mobile width (about 375 px).
- [ ] Take three screenshots: overview, add-expense dialog, and transactions/budget.
