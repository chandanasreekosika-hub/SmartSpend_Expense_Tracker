# SmartSpend AI Prompt Log

Keep a truthful record of the prompts you actually use. The prompts below are suggested starting points; edit them to reflect your real development process.

## Prompt 1 — Plan the UI
"Help me plan a beginner-friendly, responsive expense tracker website called SmartSpend for a 4-day student assignment. Use HTML, CSS, and vanilla JavaScript. Include a dashboard, monthly budget, expense form, category breakdown, search/filter, and footer. Do not use a backend."

## Prompt 2 — Build the first version
"Generate a clean expense tracker UI with separate index.html, style.css, and script.js files. Use a modern purple-and-white visual theme, semantic HTML, accessible labels, responsive desktop/mobile layouts, and beginner-readable JavaScript."

## Prompt 3 — Add functionality
"Help implement adding and removing expenses, category filtering, transaction search, monthly budget calculations, category totals, form validation, and localStorage. Explain the main functions in beginner-friendly language."

## Prompt 4 — Test and debug
"Review my SmartSpend HTML/CSS/JavaScript for bugs. Check empty input, invalid/zero amounts, mobile layout, empty transaction list, filtering, budget overrun, and browser storage. Explain fixes instead of changing unrelated parts."

## Prompt 5 — Improve the design
"Suggest meaningful improvements to my expense tracker that do not require a backend. Keep it responsive, accessible, visually consistent, and easy for a beginner to explain. List the changes and why they help."

## Reflection to complete after testing
- What did I customize?
- What issue did I find during testing?
- What change did I make to fix or improve it?
- Which JavaScript function can I explain confidently?
